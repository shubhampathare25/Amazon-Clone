# Amazon Clone

A frontend web development project replicating the Amazon homepage interface, built using **HTML** and **CSS**.

## 🚀 Features
* **Responsive Navigation Bar:** Includes logo, delivery location, search bar, sign-in, returns/orders, and cart.
* **Hero Section:** Eye-catching banner showcasing shopping categories.
* **Product Grid Layout:** Multiple category boxes displaying various products with images and links.
* **Footer:** Comprehensive footer mimicking Amazon's layout with back-to-top button and links.

## 🛠️ Built With
* HTML5
* CSS3 (Flexbox & Grid)
* FontAwesome (for icons)

📝 How to Run the Project
1. Download or Clone the Repository
    * Download the ZIP or run:
```
git clone https://github.com/shubhampathare25/Amazon-Clone.git
```
2. Open the Project in VS Code
3. Install the Live Server Extension
   * Go to the Extensions tab and search for "Live Server".
   * Click Install.
4. Start the Project
   * Open amazon.html.
   * Click the Go Live button at the bottom-right of VS Code.
   * Your browser will open the project automatically.

  ## 📁 Project Structure

```text
README.md          # Project documentation
```
